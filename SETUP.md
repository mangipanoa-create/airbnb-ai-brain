# Local Setup Guide for Airbnb AI Brain\n\n## Prerequisites\n- Python 3.11+\n- pip (Python package manager)\n- Git\n\n## Step-by-Step Setup\n\n### 1. Clone the Repository\n```bash\ngit clone https://github.com/mangipanoa-create/airbnb-ai-brain.git\ncd airbnb-ai-brain\n```\n\n### 2. Create a Virtual Environment (Recommended)\n```bash\n# On macOS/Linux\npython3 -m venv venv\nsource venv/bin/activate\n\n# On Windows\npython -m venv venv\nvenv\\Scripts\\activate\n```\n\n### 3. Install Dependencies\n```bash\npip install --upgrade pip\npip install -r requirements.txt\n```\n\n### 4. Set Up Environment Variables\n```bash\n# Copy the example env file\ncp .env.example .env\n\n# Edit .env with your settings (optional for local development)\n# Most settings have defaults for local testing\n```\n\n### 5. Create Directories for Templates and Static Files\n```bash\n# Make sure these directories exist\nmkdir -p templates\nmkdir -p static\n```\n\n### 6. Start the Application\n```bash\n# Make sure your virtual environment is activated\nuvicorn app.main:app --reload --host 0.0.0.0 --port 8000\n```\n\nYou should see output like:\n```\nINFO:     Uvicorn running on http://0.0.0.0:8000\nINFO:     Application startup complete\n```\n\n### 7. Access the Application\n\nOpen your browser and visit:\n\n**Dashboard:**\n```\nhttp://localhost:8000/dashboard\n```\n\n**API Documentation (Swagger UI):**\n```\nhttp://localhost:8000/docs\n```\n\n**API Documentation (ReDoc):**\n```\nhttp://localhost:8000/redoc\n```\n\n**Health Check:**\n```\nhttp://localhost:8000/api/health\n```\n\n## Testing the API\n\n### Using curl to test the triage endpoint:\n\n```bash\ncurl -X POST http://localhost:8000/api/triage \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"guest_name\": \"John\",\n    \"listing_name\": \"Skyline Loft\",\n    \"message\": \"The AC is not working!\"\n  }'\n```\n\n### Expected Response:\n```json\n{\n  \"intent\": \"maintenance\",\n  \"urgency\": \"medium\",\n  \"response\": \"Hi John, Thank you for reporting this. We are creating a maintenance ticket and will contact the right contractor for Skyline Loft as soon as possible.\",\n  \"requires_work_order\": true\n}\n```\n\n## Database\n\nBy default, the app uses SQLite which is stored as `airbnb_ai.db` in the project root. This is fine for local development.\n\nThe database is automatically created on startup.\n\n## Troubleshooting\n\n### Port Already in Use\nIf port 8000 is already in use:\n```bash\nuvicorn app.main:app --reload --host 0.0.0.0 --port 8001\n```\nThen access at `http://localhost:8001`\n\n### Module Import Errors\nMake sure your virtual environment is activated:\n```bash\n# Check if activated (you should see (venv) in your terminal)\nwhich python  # macOS/Linux\nwhere python  # Windows\n```\n\n### Missing Templates or Static Files\nEnsure the directories exist:\n```bash\nls -la templates/\nls -la static/\n```\n\n### Database Issues\nTo reset the database:\n```bash\nrm airbnb_ai.db\n# Restart the app and it will recreate the database\n```\n\n## Example Workflow\n\n### 1. Create a Listing\n```bash\ncurl -X POST http://localhost:8000/api/listings \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"title\": \"Downtown Loft\",\n    \"address\": \"123 Main St, Downtown\",\n    \"check_in_instructions\": \"Key is under the mat\",\n    \"emergency_contact\": \"555-0123\"\n  }'\n```\n\n### 2. Create a Guest\n```bash\ncurl -X POST http://localhost:8000/api/guests \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"full_name\": \"Alice Johnson\",\n    \"phone\": \"555-9876\",\n    \"email\": \"alice@example.com\"\n  }'\n```\n\n### 3. Create a Booking\nUse the listing and guest IDs from previous responses:\n```bash\ncurl -X POST http://localhost:8000/api/bookings \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"guest_id\": \"<guest_id>\",\n    \"listing_id\": \"<listing_id>\",\n    \"check_in\": \"2026-09-27\",\n    \"check_out\": \"2026-09-30\",\n    \"status\": \"confirmed\",\n    \"payment_status\": \"paid\"\n  }'\n```\n\n### 4. Send a Guest Message\n```bash\ncurl -X POST http://localhost:8000/api/messages \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"guest_id\": \"<guest_id>\",\n    \"booking_id\": \"<booking_id>\",\n    \"sender_type\": \"guest\",\n    \"channel\": \"sms\",\n    \"content\": \"The wifi is not working in the bedroom\"\n  }'\n```\n\n### 5. View the Dashboard\nGo to `http://localhost:8000/dashboard` to see all the data populated in real-time.\n\n## Stop the Application\n\nPress `Ctrl+C` in your terminal to stop the server.\n\n## Next Steps\n\nOnce everything is running:\n1. Explore the Swagger UI at `/docs`\n2. Create test data through the API\n3. View the dashboard to see how data flows\n4. Check logs for any errors\n\n## For Production Deployment\n\nSee the Dockerfile for containerization or deployment guides for:\n- AWS (EC2, ECS, Lambda)\n- Heroku\n- DigitalOcean\n- Railway\n- Render\n"
